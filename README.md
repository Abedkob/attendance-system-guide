# Edifice Software — user guide

A page-by-page guide to the attendance, HR and payroll system: what each screen is for, the steps
in order, what the system refuses and why, and what every dialog asks for.

**Read it here:** https://abedkob.github.io/attendance-system-guide/

The whole guide is a single self-contained HTML file (`index.html`, about 12 MB): twelve chapters
and 213 screenshots embedded in the file itself. Download it and it still works with no internet
connection.

Every name, number and date in the screenshots comes from a demo workspace. Nothing here shows a
real person.
